# 접근성

적용되어 있는 항목은 다음과 같습니다.

- **모션 줄이기.** `prefers-reduced-motion: reduce`가 설정되어 있으면 인트로와 토큰이 꺼지고 완성된 다이어그램이 표시됩니다.
- **키보드.** 다이어그램 컨테이너에 포커스를 줄 수 있습니다(`tabindex="0"`). Enter 또는 Space로 단계 모드를 시작하고, 이후에는 Space가 재생/일시정지, ←와 →가 단계 이동, Esc가 종료입니다.
- **단계 컨트롤.** 바에는 접근 가능한 이름이 있는 `role="toolbar"`가 지정되어 있고 버튼마다 레이블이 있습니다. 이전과 다음 버튼은 양 끝에서 `aria-disabled`를 사용합니다.
- **포커스 윤곽선.** 눈에 보이는 포커스 링은 `--pa-solid` 색상을 사용합니다.

**점검하지 않은 항목**은 스크린 리더로 확인하는 일과 직접 만든 팔레트의 명암비입니다. 다이어그램은 일러스트로 보고, 다른 다이어그램과 마찬가지로 핵심 정보를 주변 본문에도 함께 적으시기 바랍니다. Mermaid 소스의 텍스트는 설명을 대신하지 못합니다.
