# DESIGN.md: pele-animate.danielkimdev.com

Look and feel of the site. `SITE_DEV_PLAN.md` says what to build; this says how it should look. Keep it short; change it
when the site changes. Redesigned 2026-10-24 with the Hallmark **Bloom** theme (stamp in `site/src/app.css`).

## 1. Purpose

Get a developer from "what is this?" to an animated diagram in their project. The diagram is the loudest thing on every
page; the site's own chrome stays quiet.

## 2. Visual theme

- **Bloom.** Warm off-white paper with faint grain, umber ink, one terracotta accent, two fixed blooms (top right, bottom
  left) that never move. Dark mode is the same system re-derived on warm umber, not an inversion.
- **The diagram sits on its working grid.** The home stage draws a generated bar/beat grid that fades out from the scene.
  Never a full-strength grid across a section.
- **Distinct from pele.run.** The footer says: built on Pele by kepano (MIT), not affiliated.
- **Raised, not boxed.** Surfaces are sheets with a soft shadow (light) or a lightness step with a hairline ring (dark).
  No gradients except the grid, the blooms and the rubber cap. No illustrations beyond the diagrams.

### Tokens

Declared in `site/src/tokens.css` (Bloom, generated by the Hallmark scaffold) and overridden for dark in `site/src/app.css`.
Components use the variables, never raw colors. The old names (`--bg`, `--fg`, `--accent`, ...) remain as aliases.

| Token | Light | Use |
|---|---|---|
| `--color-paper` / `-2` / `-3` | warm off-white steps | Page, code blocks and cards, wells |
| `--color-sheet` | near-white | Raised surfaces, pills, inputs |
| `--color-ink` / `-2` / `--color-muted` | umber | Text, secondary text, labels |
| `--color-rule` | warm grey | Hairlines |
| `--color-accent` | terracotta | Links, focus ring, selected state |
| `--scene-*` | hex | Diagram scene (hex on purpose: the playground colour pickers read `--pa-*` back as `#rrggbb`) |

## 3. Typography

- **Text and heads:** Ranade (variable, 400/500/600). No serif on the site; if one returns, Gambarino, roman, once a page,
  never a head. **Code:** Geist Mono Variable (Fontsource).
- Ranade is a Fontshare face (ITF Free Font License), loaded from the Fontshare CSS API in `site/src/app.html`
  (the licence bars redistributing the files through public repositories, so they are not self-hosted).
- Heads are one weight (600) and one colour; docs prose uses a smaller head scale than the display heads. Docs text 72ch.

## 4. Layout

- Container 1440px max, 64px gutters (24px, then 16px on phones), no horizontal page scroll at any width.
- **Home:** the first screen is headline, one sentence, two actions and the live diagram on its grid; then a split (the diagram's Mermaid source in an editor panel beside three proofs), Install, Where it fits, For coding agents.
- **Docs:** three columns on wide screens (sidebar 15rem, content, table of contents 13rem); under 62rem the sidebar becomes a
  `<details>` menu and the table of contents is dropped.
- **Header:** a masthead bar on a blur backdrop: name, Docs, Icons, Playground, Changelog, GitHub, npm, theme toggle.
- **Footer:** the name set large, then credits (Pele, Tabler), licence, non-affiliation line.

## 5. Components

- **Live diagram:** the scene panel from `pele-animate.css` on the Bloom tokens, with the Mermaid source in a collapsed
  `<details>` underneath where docs show it. Never a screenshot.
- **Primary button:** a sheet pill with a rubber cap in a bezel at the left; secondary is a sheet pill. Press sinks 1px.
- **Code block:** `--color-paper-2`, inset hairline, 10px radius, Shiki high-contrast themes (light and dark).
- **Inputs:** 52px pills with a `--color-muted` edge. **Prev/next:** two raised sheets at the end of every docs page.

## 6. Motion

The diagrams animate; controls ease transform and shadow in 120 to 220ms; nothing else moves. `prefers-reduced-motion` is
honored by pele-animate and by the site (no smooth scrolling, transitions cut to ~0).

## 7. Accessibility

- Contrast of text at least 4.5:1 in both themes; input edges at least 3:1.
- Visible `:focus-visible` outline in `--color-focus`; a "Skip to content" link; one `h1` per page, headings in order.
- Semantic landmarks; the theme toggle is a button with an accessible name and state, stored in `localStorage` when
  available (the page works without it).
- Diagram pages keep the key information in the surrounding text.

## 8. Dark mode

Follows `prefers-color-scheme`. The header toggle sets `data-theme="light"` or `data-theme="dark"` on the root element and
overrides the system. pele-animate honors the same attribute. Dark is a lamp-lit umber, no glow, no pure black.

## 9. Voice

Plain words, short sentences, no marketing claims that are not measured. Say "step order", "step-by-step playback" and
"icons"; do not say "choreography" or call it a theme package.

## 10. Do and don't

- Do show code next to the result it produces.
- Don't add a third bloom, a terracotta field or card, a serif in a head, or a glow.
- Don't link to pages that do not exist; don't claim anything the build does not measure.
